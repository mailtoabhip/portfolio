# Original delivery and forest asset pack — first pass

Created from the supplied visual references. These are actual GLB meshes, not images renamed as 3D files. The supplied photos and their watermarks are not embedded.

## Included

- delivery-rigid-truck.glb — silver cab, dark cargo body, white sectional rear door; 70,740 triangles, 29 meshes.
- delivery-tractor-trailer.glb — long truck and trailer inspired by the second reference; 146,672 triangles, 61 meshes.
- forest-pine.glb — 51,772 triangles, four material meshes.
- forest-fir.glb — 51,772 triangles, four material meshes.
- forest-birch.glb — 22,228 triangles, four material meshes.
- roadside-rock.glb — 320 triangles with vertex color variation.
- textures/asphalt-basecolor.png — AI-generated photographic asphalt material.
- textures/pine-bark-basecolor.png — AI-generated photographic bark material.
- source/build-assets.mjs — editable, deterministic Three.js geometry generator.
- index.html, vendor/, serve.cjs — self-contained local model viewer; no CDN required.
- model-stats.json — measured mesh bounds, triangle counts and file sizes.

## Model features and limits

Truck features include beveled cab panels, windshield and seals, separate mirrors, grille slats, headlights, door handles, steps, fuel tanks, chassis rails and crossmembers, tire grooves, wheel hubs and bolts, roof corrugation, side rivets, markers, rear door panels and hinges, latch, tail lamps, mud flaps and underrun bumper.

Units are metres. +Y is up, and the vehicle points along -Z. Wheel hierarchy uses a steer group with a wheel_spin child: rotate the parent around Y for steering and the child around X for wheel rotation. There are no baked animation clips. The long trailer is currently static relative to the tractor: it needs a trailer pivot and articulation logic before driving.

Materials use glTF metallic/roughness properties. They currently use scalar roughness/metalness rather than baked texture sets. The two generated base-color textures are supplied separately, not embedded in these GLBs. The bark texture is for pine/fir trunks; birch needs its own bark material. No normal, roughness, displacement, collision or LOD maps are included. Seamless tiling was requested from the image generator but has not been visually verified.

These are detailed procedural first-pass assets, not production-ready hyperrealistic scans. The models still need visual art direction, texture baking, optimization and in-game lighting work. Geometry export and binary structure were checked. After fixing startup handling and the local launch flow, all six models were loaded in the browser; the truck, trailer and pine were visually inspected. Model switching completed without browser errors.

Trees have modeled branches and opaque leaf geometry rather than billboard images. They are source assets for nearby trees: make reduced-detail LODs before populating a dense forest. Truck mirrors increase the width beyond the cargo body. Refer to measured bounds; do not assume the existing game collider matches.

## Preview

On Windows, double-click **Start Preview.cmd**. Keep its window open while reviewing the assets. It starts a local-only server and opens the viewer in your default browser. Do not double-click index.html: browsers block its modules and model requests when opened as a file.

With Node.js installed, run from this folder:

    node serve.cjs

Then open http://127.0.0.1:3118 in a WebGL-capable browser. Select a model and orbit with the mouse. View controls offer front, rear and side views. Startup/import/WebGL failures and model-request timeouts now display a message instead of leaving a permanent loading label.

## Rebuild

In this folder, install Three.js 0.185.1, then:

    npm install three@0.185.1
    node source/build-assets.mjs

This recreates the GLBs and model-stats.json in this folder. It does not regenerate the image textures.

## Three.js integration

Use GLTFLoader or React Three Fiber's useGLTF to load a model. The rigid truck is the intended starting point for the existing delivery game. Offset its center to match the game's cab center, then align camera, headlights and collider explicitly. The long tractor-trailer exceeds the current delivery-bay footprint and must not be substituted without simulation changes.

For texture color maps, use SRGBColorSpace and RepeatWrapping, with repeat set according to world metres. Do not use a color map as a normal map. Start with a rough asphalt material near 0.9; tune against the actual lighting.

No game source was replaced and nothing was deployed.

## Provenance

Geometry is generated by the included source. Textures were generated with the built-in image-generation tool; prompts are included in prompts.txt. The reference photos were used for visual direction, not copied into materials. Third-party Three.js viewer files retain their MIT license in vendor/THREE-LICENSE.txt. The trucks are generic and unbranded.
